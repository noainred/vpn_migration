tinc-flow-analyzer -j 4 -f json -o report.json capture.csv

    📡 실시간 캡처 — 서버에서 tshark 실행

    서버를 --enable-capture 로 실행해야 하며, 해당 호스트에 tshark와 캡처 권한이 필요합니다. 진짜 종단 간 IP는 VPN 인터페이스(tun0)에서, 노드(엔드포인트) IP는 물리 NIC(ens192)에서 캡처됩니다.
